Ты — Senior Fullstack Developer с опытом создания AI-приложений для финансового сектора. Твоя задача — разработать веб-приложение для автоматической сверки актов сверки с контрагентами с использованием AI-агента.

---

## 📋 ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА

**Название:** AI-агент для сверки актов (Reconciliation AI Agent)

**Цель:** Создать веб-приложение, которое помогает бухгалтерам автоматизировать процесс сверки актов с контрагентами. Система загружает файлы от обеих сторон, с помощью AI распознает их структуру, извлекает данные, выполняет точное сравнение и генерирует понятный отчет с рекомендациями.

**Ключевой принцип:** Human-in-the-Loop — AI только помогает пользователю, все критические решения принимает человек.

---

## 👥 ПОЛЬЗОВАТЕЛИ

1. **Бухгалтеры (основные пользователи)** — не IT-специалисты. Интерфейс должен быть максимально простым и интуитивным.
2. **Разработчики (технические пользователи)** — для настройки и поддержки системы.

**Частота использования:** Еженедельно / Ежемесячно.

---

## 📄 ВХОДНЫЕ ДАННЫЕ

### Форматы файлов
- **Excel** (XLSX, XLS)
- **PDF** (текстовые и сканы-изображения — требуется OCR)
- Файлы могут быть в смешанных форматах (один Excel, другой PDF)

### Структура файлов
- **Может меняться** в зависимости от контрагента.
- AI должен автоматически определять структуру: в какой колонке находятся номера документов, даты, суммы, начальное/конечное сальдо, обороты.

### Поля для сравнения
- Обязательные: **номер документа**, **дата**, **сумма**.
- Дополнительные: **начальное сальдо**, **конечное сальдо**, **обороты за период** (если есть).

### Сложности в файлах (должны обрабатываться)
- Объединенные ячейки
- Разные форматы чисел (разделители тысяч, десятичные запятые)
- Спецсимволы в номерах документов (тире, слэши, буквы)
- Пустые строки или ячейки
- Повторяющиеся документы (дубли) — допустимо, так как это могут быть разные части оплаты. Каждый экземпляр считается отдельной позицией.

### Объем данных
- От **10 до 1000 строк** в одном файле.
- Размер файлов: от **нескольких МБ до десятков МБ**.

## 🔍 ЛОГИКА СВЕРКИ И АНАЛИЗА

### Что считается расхождением (все три варианта):
1. **Документ есть в одном файле, но отсутствует в другом.**
2. **Документ есть в обоих файлах, но суммы не совпадают.**
3. **Документ есть в обоих файлах, но даты или другие поля различаются.**

### Точность сравнения
- **Строгое равенство до копейки.** Никаких допусков.
- Для точных вычислений использовать библиотеки типа `dinero.js`, `decimal.js` или `big.js`.

### Группировка и дубли
- Каждый экземпляр документа считается отдельной позицией.
- Дубли допустимы (например, разные части оплаты по одному номеру).

## 🤖 РОЛЬ AI-АГЕНТА

AI-агент выполняет следующие функции **строго в режиме ассистента (Human-in-the-Loop)**:

### 1. Распознавание структуры файлов
- Автоматически определяет, в какой колонке находятся номера документов, даты, суммы, сальдо, обороты.
- Если AI **не уверен** в структуре — он **запрашивает уточнение у пользователя** через интерфейс (например, показывает варианты и просит выбрать).
- AI должен **объяснять**, почему он сделал тот или иной вывод (например: «Я определил колонку 'Сумма' по наличию чисел и заголовку 'Итого'»).

### 2. Извлечение данных
- Извлекает данные из Excel (XLSX, XLS).
- Извлекает данные из PDF (текстовых и сканов) с использованием OCR (например, Tesseract.js).
- Приводит данные к единому формату (даты, числа, номера документов).

### 3. Сравнение данных
- Сравнивает два набора данных по заданным полям.
- Находит расхождения трех типов (отсутствие документа, разница в суммах, разница в других полях).

### 4. Генерация отчета
- Создает HTML-отчет с результатами сверки.
- Визуально выделяет расхождения (цветовая индикация).
- Предоставляет детали по каждому расхождению.

### 5. Анализ и гипотезы
- Предлагает **гипотезы о причинах расхождений**.
- Например: «По документу №123 разница в сумме 500 руб. Возможно, вы не учли возврат товара» или «Документ №456 отсутствует у контрагента — вероятно, он не был отправлен».

### 6. Прозрачность решений
- Пользователь должен видеть **логику AI** (почему он сделал тот или иной вывод).
- Возможность **проследить цепочку решений** AI (например, через отображение промежуточных шагов).

## 📊 ВЫХОДНЫЕ ДАННЫЕ

### Формат отчета
- **HTML** (веб-страница), доступная для просмотра в браузере и печати.
- Возможность скачать отчет в формате PDF или Excel (опционально).

### Содержание отчета (всё перечисленное ниже):
1. **Сводка:**
   - Количество документов в вашем файле.
   - Количество документов в файле контрагента.
   - Количество расхождений по каждому типу.

2. **Документы только у вас:**
   - Список с номерами, датами, суммами.
   - Итоговая сумма.

3. **Документы только у контрагента:**
   - Список с номерами, датами, суммами.
   - Итоговая сумма.

4. **Расхождения в суммах:**
   - Список документов, где суммы не совпадают.
   - Ваша сумма, сумма контрагента, разница.
   - Указание, кто кому должен (положительная разница = контрагент должен вам, отрицательная = вы должны контрагенту).

5. **Расхождения в других полях (даты, сальдо и т.д.):**
   - Список документов, где даты или другие поля не совпадают.

6. **Гипотезы и рекомендации:**
   - AI предлагает возможные причины расхождений.
   - Рекомендации по устранению.

7. **Итоговый баланс:**
   - Общая сумма расхождений (кто кому должен).

8. **Логика AI:**
   - Краткое объяснение, как AI определил структуру файлов и пришел к выводам.

## 🖥️ ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### Платформа
- **Веб-приложение** (работает в браузере).
- **Один стек**: JavaScript/TypeScript (Full-Stack).

### Frontend (React / Vue / Svelte — на твой выбор, предпочтительно React)
- Загрузка файлов: **кнопка "Выбрать файл"** + **Drag-and-drop**.
- Индикаторы прогресса:
  - Загрузка файлов.
  - Обработка файлов (распознавание, извлечение данных).
  - ETA (оставшееся время).
- Отображение отчета в понятном и визуально привлекательном формате.
- Возможность скачать отчет.

### Backend (Node.js + Express / Fastify)
- Обработка файлов (Excel, PDF, OCR).
- Взаимодействие с AI через API OpenRouter.
- Логика сверки (детерминированная, без AI).

### AI (OpenRouter API)
- Использовать модели, доступные через OpenRouter (например, GPT-4, Claude, Mistral).
- **Только русский язык** для общения с пользователем и генерации отчетов.
- AI используется для:
  - Распознавания структуры файлов.
  - Извлечения данных из сложных PDF.
  - Генерации гипотез о причинах расхождений.
  - Формирования отчета на русском языке.
  - Объяснения своей логики.

### Библиотеки для точных вычислений
- **Обязательно использовать** библиотеки для точных денежных расчетов:
  - `dinero.js` или `decimal.js` или `big.js`.
- Сравнение сумм — строгое, до копейки.

### Библиотеки для работы с файлами
- Excel: `xlsx` (SheetJS) или `exceljs`.
- PDF: `pdf-parse` для текстовых PDF, `tesseract.js` для OCR сканов.
- Работа с изображениями: `sharp` или `canvas` для предобработки перед OCR.

### Безопасность
- Безопасность не является приоритетом (согласно требованиям заказчика).
- Однако базовые проверки (тип файла, размер) должны быть.

### Развертывание
- Бесплатные сервисы: Frontend на **Vercel / Netlify**, Backend на **Render / Railway**.
- Либо единый деплой на **Vercel** с использованием Serverless Functions.

## 👤 ПОЛЬЗОВАТЕЛЬСКИЙ ИНТЕРФЕЙС (UX)

### Основные экраны

1. **Главный экран (загрузка файлов):**
   - Две зоны для загрузки файлов (ваш файл и файл контрагента).
   - Drag-and-drop + кнопка "Выбрать файл".
   - Отображение имен загруженных файлов.
   - Кнопка "Начать сверку".

2. **Экран обработки:**
   - Индикатор прогресса (загрузка → распознавание → извлечение → сравнение → генерация отчета).

5. **Экран "Логика AI":**
   - Показывает промежуточные шаги AI.
   - Объяснение, почему AI определил структуру именно так.
   - Возможность скорректировать логику (для разработчиков).
